## Задание 1

### Условие:

Замыкание-калькулятор, накапливающее результат и поддерживающее 4 арифметичесике операции: сложение, вычитание, умножение, деление

### Описание проделанной работы

Код создаёт калькулятор‑замыкание с операцией деления и начальным значением 0. При вызове calc() выполняется вычисление. Это значение возвращается и выводится на экран, а также сохраняется внутри замыкания для следующих вызовов.

## Задание 2

### Условие: 

Декоратор, который будет запускать функцию указанное число раз с указанными параметрами и возвращать последвательность результатов.

### Описание проделанной работы: 

Декоратор repeat запускает функцию заданное число раз (times, по умолчанию — 1) с теми же аргументами и возвращает список результатов всех вызовов.

Коротко по шагам:

  Принимает параметр сколько раз выполнить функцию.
  
  Оборачивает целевую функцию во внешнюю функцию.
  
  В цикле вызывает функцию, передавая одни и те же аргументы и операции.
  
  Собирает результаты каждого вызова в список.
  
  Возвращает список results.

## Задание 3

### Условие: 

Применить декоратор к замыканию

### Описание проделанной работы: 

Реализована итеративная функция для вычисления x_i по заданной рекуррентной формуле. Для i = 1 и i = 2 возвращаются начальные значения. Для i ≥ 3 используется цикл, в котором последовательно вычисляются значения с сохранением двух предыдущих результатов. Тестирование при i = 3 дало корректный результат.
